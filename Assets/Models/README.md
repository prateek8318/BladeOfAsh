# Realistic hero models (Mixamo)

Put files in `Assets/Models/<Hero>/` (Hero = Kael, Ysra or Gorrun), then run
`Blade of Ash > Build macOS App`. The game uses the model automatically;
if a folder is empty, the built-in body is used.

| File | What to download from mixamo.com |
|---|---|
| `Character.fbx` | The character. Format **FBX for Unity**, **With Skin**, T-pose |
| `Idle.fbx` | e.g. "Great Sword Idle" |
| `Run.fbx` | e.g. "Great Sword Run" — tick **In Place** |
| `Sprint.fbx` (optional) | any sprint — In Place |
| `Attack1.fbx` `Attack2.fbx` `Attack3.fbx` | three "Great Sword Slash" variants |
| `Heavy.fbx` | "Great Sword Jump Attack" or a big overhead slash |
| `Spin.fbx` (optional) | "Great Sword High Spin Attack" |
| `Dodge.fbx` | a forward roll — In Place |
| `Block.fbx` | "Great Sword Blocking" (idle block) |
| `Hit.fbx` | "Great Sword Impact" |
| `Death.fbx` | "Great Sword Death" |
| `Throw.fbx` (optional) | any throw |
| `Ult.fbx` (optional) | "Battlecry" / "Great Sword Casting" |
| `Execute.fbx` (optional) | a strong two-handed finishing slash |

All animation files: **FBX for Unity**, **Without Skin**, **30 fps**.
File names must match exactly (case-sensitive).
